Student Performance Analysis Dashboard

Project Overview

This project uses Power BI to analyze student academic performance and identify factors that influence learning outcomes.

The dashboard provides insights into:

- Overall student performance
- Gender-based performance comparisons
- Impact of test preparation
- Ethnicity-based performance trends
- Top-performing students
- Lowest-performing students

Tools Used

- Power BI Desktop
- DAX (Data Analysis Expressions)
- Data Visualization
- PDF Reporting

Dashboard Features

KPI Cards

- Total Students
- Average Math Score
- Average Reading Score
- Average Writing Score
- Overall Performance Score

Visualizations

- Gender Performance Analysis
- Test Preparation Impact Analysis
- Ethnicity Performance Analysis
- Top 10 Students
- Bottom 10 Students

Key Findings

- Students who completed test preparation performed better across all subjects.
- Performance differences between genders were relatively small.
- Ethnicity groups showed moderate variations in average scores.
- Identifying high and low performers helps support targeted interventions.
